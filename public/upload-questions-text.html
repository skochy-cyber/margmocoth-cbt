Supported Format

Save your Word document as .txt or copy-paste into a .txt file. Each question block must follow this pattern:

Q: What is the powerhouse of the cell? A: Nucleus B: Mitochondria C: Ribosome D: Golgi apparatus Answer: B Q: Which vitamin is produced by sunlight? A: Vitamin A B: Vitamin C C: Vitamin D D: Vitamin K Answer: C
  • Separate questions with a blank line
  • Labels are case-insensitive: Q:, Question:, 1. Q: all work
  • Answer must be A, B, C, or D
  • Math: wrap expressions in $...$ e.g. $x^2 + y^2 = r^2$
  • Upload as many questions as you want — pool size controls how many each student sees
